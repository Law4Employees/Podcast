# KBN Florida Employee Rights Weekly

A private weekly podcast feed: new Eleventh Circuit and Florida appellate employment decisions, plus new EEOC, DOL and NLRB guidance.

- Feed for podcast apps: https://law4employees.github.io/Podcast/feed.xml
- Web page: https://law4employees.github.io/Podcast/

Episodes are produced each Monday by a scheduled Claude task, which runs `publish.py` to add the episode and rebuild `feed.xml` and `index.html`. The newest 26 episodes are kept.

Prepared with AI for private use. Not legal advice.
